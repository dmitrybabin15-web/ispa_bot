# ispa_host bot

Deploy-ready Telegram-бот на aiogram 3.

## О проекте

Бот публикует список мастеров массажного салона, которых страница мастеров сайта i-spa.su помечает фразой «Ждёт вас сегодня». Он получает этот список с сайта, обновляет сохранённые данные и отправляет сообщение с именами мастеров, адресом и контактами.

Публикация выполняется автоматически ежедневно в 11:30 по часовому поясу `Europe/Moscow`; время задаётся через `DAILY_PUBLICATION_HOUR` и `DAILY_PUBLICATION_MINUTE`, часовой пояс — через `TIMEZONE`. Администратор также может вручную запустить обновление, отправив боту сообщение: бот обновит список и опубликует его в том же чате. В сообщении есть кнопки перехода на сайт и на внешнюю страницу записи. Сам бот запись не создаёт.

## Быстрый запуск

```bash
./deploy.sh
```

Или:

```bash
docker compose up -d --build
```

## Логи

```bash
docker compose logs -f bot
```

## Автоудаление сообщений

Все сообщения, которые бот отправляет через `send_message_with_auto_delete`, записываются в таблицу `bot_messages` и удаляются через `BOT_MESSAGE_TTL_SECONDS=86399`, то есть через 23 часа 59 минут 59 секунд.

Удаляются именно сообщения бота. Пользовательские сообщения бот не трогает.
