# Деплой

Проект уже подготовлен к запуску: внутри есть `.env` с настройками, `Dockerfile`, `docker-compose.yml` и папка `db-data` под SQLite.

## Запуск на сервере

```bash
unzip ispa_host_deploy_ready.zip
cd ispa_host
./deploy.sh
```

Либо вручную:

```bash
docker compose up -d --build
```

## Проверка

```bash
docker compose logs -f bot
```

## Остановка

```bash
docker compose down
```

## Что уже настроено

- Бот запускается через Docker Compose.
- База SQLite хранится в `./db-data/db.sqlite3`, то есть не пропадает при пересборке контейнера.
- Сообщения, отправленные самим ботом, удаляются через `86399` секунд — 23 часа 59 минут 59 секунд.
- После перезапуска бот восстанавливает ожидающие удаления сообщения из базы.
- Раз в минуту запускается страховочная очистка просроченных сообщений.
